# Existing canonical owner ASR binding (opt-in)

`SpeechRoutes` now supplies `createOwnerAsrResolver()` to `/speech/transcribe-local`. Defaults remain unavailable. An administrator may set `AGNT_LOCAL_ASR_CONTRACT` to the workstation owner's published `interfaces/consumer-contracts/voice-dictation.env` and `AGNT_LOCAL_ASR_USERS` to an explicit comma-separated list of authenticated AGNT user IDs. No wildcard, client endpoint, account fallback, copied credentials or model override is supported. This batch does not alter live server configuration.

The resolver reads at most 32 KiB as data, never sources shell, and requires the v1 voice-dictation ready ASR `speech-stream` contract. Only primary URLs are used; effective/legacy aliases do not silently substitute. Both endpoints must share a literal IPv4 loopback port, have no credentials/query/fragment, and match the reviewed root WebSocket and `/health` paths. Redirects are refused. Each request has a bounded health read (8 KiB, 3 seconds), requires healthy + model_loaded, and opens a fresh socket with a 64 KiB message bound. The reviewed owner Nemotron wire contract is 16 kHz mono s16le; a contradictory health sample rate fails closed.

This is consumer binding to the **already running canonical ASR**, not a GPU allocation/admission grant, model promotion, cryptographic endpoint attestation, or speech-fidelity qualification. The administrator owns installation-path selection and OS/service integrity. Existing caller authentication remains the route's real `requireAuthHeader`; resolver tests use explicit unit identities and do not prove real-account entitlement.

The HTTP handler reserves ownership before asynchronous resolution. Its original total deadline includes that stage; disconnect/timeout suppress late socket creation. Unavailable lookup consumes no audio attempt ID; actual socket attempts retain the bounded replay window. A new frontend `apiBase` option supports the host's selected installation/isolated backend rather than hardcoding same-origin `/api`.

Still unfinished: rendered local capture/control selection and canonical TTS output integration; actual authenticated selected-model UI save/reload and post-gain speech-ASR dogfood; faster-Qwen streaming admission/qualification; human microphone and acoustic acceptance. Streaming TTS remains unbound. Do not treat healthy ASR registration as these gates passing.
