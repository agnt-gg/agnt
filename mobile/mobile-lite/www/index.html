AGNT Chat

Set your AGNT server once (LAN or Tailscale). It is saved on this device — no rebuild when the host changes. Pair with a desktop code when needed.

Saved in this app. Example: Tailscale http://100.x.x.x:3333

Server URL is stored as agnt_lite_server_origin in local storage. Optional Makefile pin AGNT_SERVER_URL only affects cold start of a fixed build — this screen overrides the host for day-to-day use in local mode.
